# PRD-003 访问控制

使用者按已安装应用选择谁进入隧道。列表顶部提供系统应用、国内应用和浏览器三个集合。集合默认按当前安装计算。在编辑里改过内置集合的成员并确认固定后，改用保存的包名，直到恢复自动计算。只改名称或说明不会固定成员。浏览器集合包含国内和国外的网页浏览器，这些应用不再计入系统集合和国内集合。隐藏系统应用只影响名单行是否显示，不改变未固定的集合成员，也不从编辑列表里拿掉这些应用。点选集合时：未全选则选中全部当前成员，已全选则只取消这些成员，其他已选应用保持不变。空集合不可点。编辑集合时，名称和说明与成员列表分在两段，成员列表占满剩余高度，保存始终在弹层底部。

离开这个列表时立刻保存并返回。隧道重载和 WebDAV 同步在返回之后进行，不挡住页面关闭。只有这份名单正在驱动已运行的隧道时才重载：没有生效分流策略时是全局名单，有生效策略时是那一份策略。全局名单和全局模式只在应用分流的「默认回退」里编辑，网络设置不重复提供入口。

规格见 [访问控制](../../systems/access-control/INDEX.md)。代码位置见 [追踪](../traceability.md)。
