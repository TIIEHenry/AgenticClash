# 界面

`app` 放 Activity 和应用级入口：主界面、配置、代理、设置、日志、访问控制、分流策略、WebDAV、外部控制。

`design` 放屏幕。Activity 创建对应的 `*Design`，再把请求送回 `app`。服务、配置和隧道逻辑仍留在 Activity 与 `service`。

显示名是 AgenticClash。`applicationId` 是 `universe.agentic.device.clash`，`clash://` 和 `clashmeta://` 仍用来导入配置。外部控制 action 由当前 `packageName` 拼接，清单字面量同为新包名。launcher 与关于页用 `application_name` / `launch_name`。内核名称仍是 Clash Meta Core。

取舍见 [ADR-002](../../../dev/decisions/002-compose-ios-home.md)。

## 首页层级

首页按使用顺序排。模式、实时上下行和当前节点参考了 [Clash Verge Rev](https://github.com/clash-verge-rev/clash-verge-rev) 的首页卡片。侧边栏、系统代理和 TUN 两套开关、IP 检测、测速和系统信息没有搬过来。Android 只有一条 VPN，连接按钮仍是唯一的隧道开关。

1. 连接状态是唯一主操作，画成状态卡里的圆形电源键。状态行左侧是呼吸点。运行中右侧是隧道已运行时长，格式是时:分:秒，小时不按 24 取模。时长优先读服务进程写下的 `tunnel_started_at`；文件不在时，从这次界面第一次看到隧道在跑开始计。停止且没有配置时，电源键打开配置列表，不尝试启动。已有配置时才是连接。停止不需要确认。电源键下面是连接或断开，再下面一行是当前配置名和模式短名。
2. 模式是状态卡里的三个等宽分段，顺序为规则、全局、直连，选中项下面有一行说明。它只写入当前会话的 override。说明下面始终有「仅本次会话有效」，字色比说明更浅。隧道模式是 Script 时三个分段都不选中，也不显示模式说明，会话提示仍在。代理页不再提供模式菜单。
3. 隧道在跑且当前组有选中节点时，状态卡下面另有一张出口卡：标签、延迟色块、节点名，组名与节点名不同时写在下面。直连，或组里没有当前节点时，不画这张卡。不显示国旗、出站 IP 和机房，核心没有把这些交给界面。有可选节点时点整张卡打开快捷切换，否则打开代理页。组的选取见 [主界面](../../../app/docs/activities.md)。
4. 流量是独立的一张卡，停止时也在。上传用绿色，下载用强调色，各显示当前速率。有至少两个采样时，下面是最近约 36 秒的折线；没有采样时不留这块空白。有累计时写在折线下面。速率来自 `queryTrafficNow()`，累计来自 `queryTrafficTotal()`。停止时速率显示 `0 B/s`，采样和累计都清空。
5. 「正在使用」是两列六格，格内图标在标题左侧：应用分流、WebDAV、外部资源、文件与 Geo、配置、代理。分流格写当前名单、模式和个数。WebDAV 写未设置、自动同步或已配置；有过同步时后面带上经过时间。外部资源在连接前写「连接后可用」，连接后写个数；点它在连接前只提示，不打开页面，连接后打开节点页的外部资源分段。文件格写当前配置名、`clash` 目录里实际存在的 Geo 文件，以及当前配置的 Age 私钥是已设置还是未设置，不写出密钥本身。点文件格时，当前配置已导入就打开这份配置的文件，否则打开 Meta 功能设置。代理格在连接前不可点，文案同样是「连接后可用」；连接后写模式短名。
6. 标题右侧是日志、重载内核。核心没跑时点重载，提示先连接。关于在设置页的「其他」。设置在底栏，首页不再放设置入口。
7. 底部五个 Tab 在同一个主界面里切换。从左到右是节点、配置、仪表盘、分流、设置，仪表盘在正中。节点、配置、分流、设置作为 Tab 时不画返回。点当前 Tab 不重新打开。点仪表盘切回首页。系统返回在这四页时先回到仪表盘。属性、访问控制、网络、覆写、Meta、WebDAV、关于、日志和文件这些再往里的页面盖住这排 Tab。访问控制只从应用分流的默认回退或某份策略进入，网络设置不再提供入口。

设置页分成「偏好」（应用、网络）、「高级」（覆写、Meta、WebDAV、本地 MCP）和「其他」（关于）。应用行右侧是当前深色模式。应用页的「界面」第一项是语言，点整行从旁边弹出菜单：第一项是跟随系统，后面按 `locales_config.xml` 的顺序列出已支持的语言，名称用该语言自己的文字。没有保存过、值为空或无法识别时跟随系统，并尊重系统语言以及 Android 13 起的按应用语言。选中后写入 `ui` 偏好的 `app_language`，立刻重建界面。页面标题在重建时按当前语言重新读取，不沿用系统缓存的旧标题。`:background` 启动时读取同一项；进程已在运行时，下一次取文案使用新语言，已经显示的通知保持到下次刷新。网络行是协议栈，WebDAV 行与首页同一句状态，本地 MCP 行是已关闭、正在监听或未在监听。放不下行尾的值改到标题下面。覆写和 Meta 仍各有一句说明。从子页返回后这些值重新读取。点进去仍是分组列表，字段写回原来的属性，不另开一套请求。本地 MCP 页有监听开关、一段用途说明、地址、令牌，以及八个工具的用途列表；开关写进 `ServiceStore` 并拉起 `:background` 的前台服务。协议见 [本地 MCP](../mcp/INDEX.md)。关于是独立页面，固定四段：应用身份头、开发者、社区、应用信息。身份头是启动图标、名称、`vX.Y.Z (Build N)` 和一句介绍，不含更新操作；图标由 `AboutActivity` 从安装包读取，不在设计模块另存一份。开发者组依次是 `Clarence Henry`、一句话介绍、邮箱、酷安、公众号；邮箱发 `mailto:`，酷安打开外链，公众号整行复制并提示「已复制」。公众号与 QQ 频道下面各有一行「显示二维码」，弹窗展示随包资源，关闭后焦点回到该行。社区组依次是 Telegram 频道和 QQ 频道；本应用没有 QQ 群聊，整行省略，不留占位。应用信息组依次是开放源代码、开源许可 `GPL-3.0`、引用开源；引用开源进入二级页，按名称排序列出 ClashMetaForAndroid 与 mihomo 的作者和许可证，AOSP、AndroidX 与 AgenticUILibrary 不列入。外链行尾是外链标记，复制行尾是复制图标，二级页行尾是箭头。整行读屏名称是标签、值和动作。检查更新与更新日志不在关于页。信息常量只有 `AboutContent` 一份，界面只读它。

## 视觉

新屏幕在 `design/src/main/java/universe/agentic/clash/`，包名 `universe.agentic.clash`。浅色页面底是 `#F3F4F6`，卡片白；深色页面底是 `#121212`，卡片 `#1E1E1E`。强调色浅色 `#587894`、深色 `#6A87A1`，只用在开关打开、主按钮、滑过的进度、链接和选中的单选或复选标记上。运行状态用呼吸点，断开和破坏性操作用红字。亮暗跟随现有 `UiStore.darkMode`。官方 Compose 没有 Cupertino 组件库，所以不引入 Cupertino 依赖。列表行、分组偏好行、开关和搜索框的源码复制自 AgenticUILibrary（Apache-2.0），放在 `design/src/main/java/nota/ui` 和 `universe/agentic/ui/search`，尺寸由 `shellIos*` 覆盖成现在这套：分组卡圆角 16dp、单行最低 52dp、双行最低 64dp、行内不画分割线、开关 40×22 且打开色是强调色、搜索条高 40dp 的胶囊。圆角只使用 0、4、8、12、16 和胶囊，定义在 `ShellShapes`。屏幕只调用 `Ios*` 封装。深色仍由 `AgenticClashTheme` 按 `UiStore.darkMode` 提供，不读系统夜间模式。

首页标题和另外四个根页面一样，是 48dp 栏里的 20sp。状态卡圆角 16dp。分组行标题 16sp，说明和右侧当前值 13sp，箭头 16dp，行首是 28dp 灰底圆，图标用正文色。最小点按仍是 44dp。导航栏高 48dp，标题 20sp，背景与页面相同，返回图标用正文色，按下时在图标后淡入圆点。带导航栏的屏幕把内容裁在导航栏下面，后画的导航栏盖住漏出来的部分，滚动时标题保持完整。设置顶层也用这个脚手架。底栏内容区高 56dp，文字 12sp。选中项是细线图标，线宽 2.25，图标 24dp，后面有一块 48×28 的 12% 灰胶囊。未选中是同一套细线，线宽 1.5，图标 22dp，没有胶囊。文字选中用主文字色加粗，不用强调色。按下只把整格前景压暗。系统导航条的高度另加在内容区下面。分段控件高 40dp 的胶囊，选中块是白或深灰，字重加粗。主按钮高 44dp、胶囊形。代理、配置、日志、文件和访问控制的列表卡圆角 16dp。当前项是 12% 的灰底加半粗标题。单选是右侧圆环，多选是 4dp 圆角的方框。分组行的说明若把字号收到九成二以上就能排进一行，就排进一行。收不动、末行又只剩一个字时，从上一行多留出约两个字的空。不把整段拆成等长的两行。WebDAV 自动同步的简体、繁体和香港说明是一整句。关于页和安装包损坏页的网址在每个斜杠后可以换行。网络里的协议栈选项用中文。覆写和 Meta 里不超过一行的短值显示在行尾，放不下或含换行的值留在标题下面。重置按钮是红色。嗅探分组的标题是「嗅探设置」，其中一行是「嗅探策略」。DNS 的策略标题仍是「策略」。

底栏五个主 tab 之间切换时，新页淡入 200ms，曲线 `ease-out`；旧页在同一帧移出，不做淡出、位移，也不做横滑。进入二级页仍是新页从右侧整屏滑入 300ms，旧页只移 1/3 屏宽并淡出 200ms；返回反向。设置子页的淡入是 250ms。系统关闭动画时直接切换。

切 tab 或进二级页之前，页面自己保存滚动位置、当前分段、展开项、搜索词和多选。滚动位置用 `firstVisibleItemIndex` 加 `firstVisibleItemScrollOffset` 持续写入，返回时直接定位，不播滚动动画。数据键没变就不重新请求；失败的空列表回来仍停在失败。现在底栏切页时，仪表盘留在组合里（尺寸置 0，并且不绘制），另外四页的 `View` 留在 `FrameLayout` 里并只切 `VISIBLE` / `INVISIBLE`，所以页面状态跟着实例留下。收起的仪表盘如果继续绘制，标题上 `requiredSize` 的日志图标会画在窗口左上角，被淡入的页面透出来。以后若改成按需创建，要用 `SaveableStateHolder` 按 tab 存同一组状态。

`ShellPages` 里仪表盘是 Compose 内容，用 `graphicsLayer` 驱动透明度；另外四页是 `AndroidView` 里的真实 View，图层变换不一定生效，所以对宿主 `FrameLayout` 用 `ViewPropertyAnimator` 做同样的 200ms 淡入。两条路径都在 `tab` 变化时从 0 开始，首帧就是透明的，不会先闪一下。二级页的进出仍由 Activity 的窗口动画承担。

底部弹层贴着屏幕两侧，只圆顶部 16dp。下沿取所在 Activity 根视图上已经应用的系统栏和刘海底边，与 Compose 导航栏底边中较大的那个，卡片内部再留 16dp。最大高度在布局时一次算出，是可用高度减去下沿和导航栏，再留 8dp。弹层高于剩余高度时可以滚动，宽度不超过 480dp。预览出口这种长列表把弹层定高，列表只排可见行。不要用「已画出的高度超出多少」再反向增加底部内边距：那会让高度、内边距互相推动，长列表会把主线程卡在测量和绘制里。遮罩不使用系统窗口变暗：浅色约 16% 黑，深色约 48% 黑。打开时遮罩淡入、弹层从屏幕底部滑入，300ms；关闭 200ms，然后再执行选中项并收起。普通动作用正文色，破坏性动作用红字。动作之间有分隔线。配置、文件和访问控制里只有几个动作的更多菜单从按钮旁边弹出：左对齐，圆角 12dp，没有遮罩，也没有取消。删除应用集的确认是贴底确认框：取消是灰胶囊，确认是红字。语言、深色模式、协议栈、覆写和 Meta 里的短选项、日志级别，都从那一行旁边弹出，当前项打勾，行尾没有进入页面的箭头。语言项较多，菜单超出屏幕时在菜单内滚动。默认回退的模式菜单从卡片上的更多图标旁弹出。节点页的排序和「排除不可选」从更多按钮旁边弹出，分成排序和筛选两组。这些都不再铺底部表。覆写重置、Meta 重置和清空日志的确认是破坏性的，红色跟随 `UiStore.darkMode`。未保存退出的确认不是破坏性的。

空列表写「这里是空的」。搜索没有结果写「没有匹配结果」。`empty` 仍表示置空。没有组的代理页仍用原来的空组说明。访问控制在没有关键字且应用表为空时仍用集合空说明。多选的选中是实心方框里的勾，半选是短横；单选是右侧圆环。只显示的标签是 18dp 高的胶囊，实心填色、白字。

代理页有组时，导航末端是更多、列表切换和测速。没有组时这三项都不放。隧道还没连上时组列表为空，节点页显示空说明；配置加载完成后重新查询组名并自动出现组，不需要切走再切回。测速进行时闪电收起，进度显示在列表上方，不盖住标题。进度留到这次测速自己的重载把延迟画上为止。打开、排序或切换组带回来的结果保持进度。被丢掉的旧结果也不清掉进度。当前节点名放不进行尾时改到标题下面。日志列表没有历史文件时不显示清空。文件日志的导出和删除是图标。实时日志的关闭仍是文字按钮，入口一行是「实时日志」。

关于和确认是同一张 Compose 卡片：圆角 16dp，宽不超过 480dp，竖屏贴底、横屏居中，四周留 16dp。取消是灰色胶囊，确认是主题色胶囊，破坏性确认是红字。点确定只关闭关于。文本、列表、映射、二维码、拉取进度和策略名称继续 inflate 原来的布局。这些 Material 对话框的卡片是分组背景，圆角 16dp，按钮色浅色 `#587894`、深色 `#6A87A1`。Snackbar 的背景、文字和动作色按 `UiStore.darkMode` 取分组色、标签色和蓝色。

## 其余屏幕

代理、提供者、配置、新建、属性、文件、日志、访问控制、分流策略，以及应用、网络、覆写、Meta、WebDAV、关于、安装包损坏和崩溃页，根视图都是 `ComposeView`。规格是 [其余屏幕的分组交互](../../../dev/plans/compose-remaining-screens.md)。订阅二维码、单行文本、列表和映射编辑器、age 密钥对话框、拉取进度仍用原来的布局。确认走 Compose。页面级 XML 已删除。

和首页同一套约定：44dp 最小点按，按压是背景闪一下，insets 来自 Design 的像素监听，深色读 `UiStore.darkMode`。根页面标题都是 20sp。

- 代理页用「节点 / 外部资源」分段。节点段一次只显示一个组。首页当前节点把选中的组名放进非导出的 extra。组名列表为空时不加载第 0 组。只有用户在组列表里点选才写 `proxyLastGroup`。同一组里后返回的旧查询不改变列表顺序，也不改变勾选。查询还在路上就点选时，列表可以更新，勾选留在点中的节点。外部资源段沿用原来的更新；查询失败时显示不可用。内联资源不提供更新。
- 文件子目录返回根目录时，新建按钮立刻消失，不等列表换回来。根目录不新建。此时若仍收到新建请求，直接返回。目录不显示大小和经过时间。修改时间小于等于 0 的文件也不显示经过时间。有更多操作的文件，更多是行尾图标，菜单从该图标旁弹出，没有标题，点行仍打开。分流策略页标题是「应用分流」，同一页有策略、应用集、访问列表三段。生效策略是 12% 灰底、半粗标题和右侧单选，不另放「生效中」。再点已生效的自定义策略不取消，保持选中。模式标签是灰底。选择分组时标题改成「选择分组」，并画出返回；当前组同样是灰底、半粗和右侧单选。策略卡在名单完整包含某个应用集时写「覆盖」。首页六格说明在第一个间隔处换行。访问控制的排序留在更多菜单里，点开后换成四个带勾选项，不再打开底部表。应用集卡显示真实应用名；内置集不提供删除。从应用分流进入的编辑关闭后回到应用分流。访问列表打开当前策略的访问控制，没有生效策略时打开全局名单。默认回退卡的模式菜单从更多图标旁弹出，当前项打勾；有生效策略时，卡下面写「仅在未选择分流策略时生效」。允许全部时第二行只有模式名。其余模式的已选数量用 `selected_apps_count`，简体写「已选 %d 个应用」，繁体和香港写「已選 %d 個應用」。从某份策略进入名单时，窗口标题是该策略的名称。没有策略 UUID 时，标题是「全局应用名单」。网络设置只放 VPN 开关、私网绕过、DNS 劫持、允许绕过、IPv6、系统代理和协议栈，不再有访问控制模式或包列表。名单页在应用列表上方显示已选数量。实时日志的级别用翻译后的名称，搜索也能匹配这个名称。搜索框的清除按钮读作「清除」。行尾短值按宽度计算，一个汉字算两个拉丁字母。WebDAV 放得下的地址和账号显示在行尾，长地址留在标题下面。已导入且不是文件的配置，更新图标在副标题右侧，读作「更新」，点它仍走原来的单个更新。图标一点就转，转到这次更新成功或失败为止；全部更新时顶栏和每一行一起转。手动更新失败只在页面上弹 toast，不发系统通知；后台定时更新仍发进行中、成功和失败通知。首页重载、外部资源的更新也是一点就转。能分享的订阅，二维码图标和更新排在同一行。更多在标题行右上角。菜单从该图标旁弹出，不再放更新，也不再显示配置名，其余动作不变。配置页另有文件分段。每份已导入配置的副标题是其根目录条目个数和这些文件的大小，点它打开原来的文件页。`clash` 目录里实际存在的 Geo 文件各自一行，副标题是文件大小和修改经过时间，点它打开 Meta 功能设置并滚到 Geo 文件。没有 Geo 文件时那一行同样滚到这一组。生效中的配置另有一行 Age 私钥，只写已设置或未设置，点它打开属性。生效中的配置不另放标签，整行用 12% 灰底和半粗标题表示。生效中的配置点行打开属性。未生效的点行仍设为当前。配置行不显示箭头。多于一份时，行首握把长按后可以拖动排序；顺序只留在本机，不进入 WebDAV，也不改创建时间。新配置排在已排好的列表后面。已过期的到期日前面写「已过期」，这一行是红色。普通订阅不重复写类型。文件、外部和未保存仍写类型。已用流量在下载小于 2 时不显示。总量大于 1 时写成「已用/总量」，后面带上和用量条相同的百分比，否则只写已用。用量条仍只在总量不少于 2 时出现。有到期日时行上不写更新经过时间。没有到期日时，更新经过时间写在副标题里，不占行尾。
- 配置页的加号从按钮旁弹出菜单，不再进入二级页：第一组是文件、URL、二维码，第二组是外部提供者，没有外部提供者时不显示。
- 每个配置的标题行右侧有预览出口按钮，读作「预览出口」，文件类型的配置也有。预览是只读的：读 `pending/<uuid>/config.yaml`，没有待提交目录时读 `imported/<uuid>/config.yaml`，用该配置的 Age 私钥解密，只解析 `proxies`、`proxy-groups` 和 `proxy-providers`。不临时加载内核，不改当前隧道，不套本地覆盖，也不下载远程 provider 的正文。面板按「分组 / 节点 / 外部资源」分段，空的一段不出现。分组先只显示组名、类型和已声明的成员个数，点开才列出该组成员。`include-all`、`include-all-proxies`、`include-all-providers` 写成「包含全部节点」，不计入成员个数，也不展开成具体节点。节点段只列 `proxies` 里的内联节点，名字在左，协议写在行尾的次要文字上，不跟分组里的成员叠成一张长表。外部资源段只显示名字和类型。远程 provider 的正文不下载、不解析。解析失败时面板显示错误，不影响配置列表。
- 实时日志用整表快照，最新一行在顶部，只有垂直滚动停在顶部才跟随。文件日志最旧在顶部，不跟随。
- 访问控制的搜索不替换完整应用表。隐藏系统应用的开关与保存的布尔相反。全选是清空后再写入当前表。
- 配置属性里，age 密钥只显示已设置或未设置。文件类型的来源和间隔显示不可用。自动更新点开后是预设下拉：已禁用、15 分钟、30 分钟、1 小时、6 小时、12 小时、24 小时，最后是「自定义…」。选中预设直接写回间隔；自定义仍打开原来的分钟输入和 15 分钟下限校验。新建配置后进入的也是这一页，所以添加和编辑共用这套候选。
- WebDAV 手动同步、拉取、推送先确认再发送，这四行和测试都不画进入页面的箭头。打开自动同步不确认。同步或测试进行中拨开自动同步，开关和存储都保持关。不忙时从关到开仍立即发同步。密码行只写已设置或未设置；编辑框不回填已存密码，留空确认保持原值，点「清除」才清空。密文读不出来时密码行和首页 WebDAV 格都写「无法读取，请重新输入」，编辑框提示同样改成这句，重新输入后恢复。
